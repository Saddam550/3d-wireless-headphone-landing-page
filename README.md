# 🎧 Designhub - 3D Wireless Headphone Landing Page

An ultra-modern, high-performance landing page designed for a wireless headphone collection. It features real-time 3D rendering, color customization, and buttery-smooth scroll-triggered animations.

## 🚀 Built With
- **HTML5 & CSS3**
- **Tailwind CSS** (for styling & utility classes)
- **Three.js** (for 3D WebGL procedural modeling and rendering)
- **GSAP & ScrollTrigger** (for scroll-based cinematic animations)
- **Lenis** (for silky-smooth scrolling experience)

## ✨ Key Features
- **Interactive 3D Model Showcase:** Built-in procedural 3D headphone model with studio lighting and reflections.
- **Real-Time Color Switcher:** Instantly update the headphone primary and cushion colors dynamically from the UI.
- **Scroll Animations:** Multi-stage GSAP scroll timeline smoothly transitions the 3D model across different sections.
- **Fully Responsive:** Optimized for both desktop and mobile viewports.
